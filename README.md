# Pixora – Image Gallery

A responsive and interactive image gallery built using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

## Features
- Responsive gallery layout
- Category-based image filtering
- Interactive image lightbox
- Next and previous image navigation
- Keyboard navigation using arrow keys
- Close lightbox using the Escape key
- Smooth hover transitions

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or your browser.

## Project Structure
- `index.html` – Gallery structure
- `style.css` – Styling and responsive layout
- `script.js` – Gallery interactions and lightbox functionality
